📚 Study Tracker
A robust Django-built web application designed for managing study sessions, tracking academic subjects, and analyzing daily productivity and study statistics.
🌐 Live Demo: https://sarakhodaverdi.pythonanywhere.com (https://www.google.com/search?q=https://sarakhodaverdi.pythonanywhere.com) 
✨ Features
 Study Session Management: Track and organize study hours across different academic subjects.
 Progress Analytics: View performance statistics and stay on top of your learning goals.
 Secure Backend: Powered by Python and Django framework.
🛠️ Tech Stack
 Backend: Python, Django
 Database: SQLite (Development)
 Deployment: PythonAnywhere
 Environment Management: Virtualenv (.venv)
🚀 Getting Started Locally
1. Clone the repository:
git clone https://github.com/sarakhodaverdi/StudyTracker.git (https://www.google.com/search?q=https://github.com/sarakhodaverdi/StudyTracker.git)
cd StudyTracker
2. Create and activate a virtual environment:
python -m venv .venv
source .venv/bin/activate
3. Install dependencies:
pip install -r requirements.txt
4. Run database migrations:
python manage.py migrate
5. Start the development server:
python manage.py runserver
